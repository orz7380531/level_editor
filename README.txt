============================================================
  虫子大作战（Bug Rush）
  关卡编辑器，可以自己做小关卡，你可以自己布置关卡要素并保存到本地进行游玩。
============================================================

【运行方式】
  双击 index.html，用 Chrome 浏览器打开即可游玩。
  无需安装任何软件，无需网络连接。
  所有资源均已本地打包，零外部依赖。

【操作说明】
  WASD / 方向键    = 移动与跳跃
  空格              = 跳跃（同上）
  鼠标左键点击     = 放出小虫子探路
  K 键              = 自杀（快速重开）
  F2               = 打开关卡编辑器

【玩法介绍】
  你是一只饥饿的虫子。你的目标：
  1. 穿越危险的厨房，入侵冰箱获得食物
  2. 吃饱后活着回到巢穴

  核心机制：
  - 饱腹度持续下降，归零即死
  - 吃食物（绿色圆点）+10 饱腹度
  - 饱腹度影响跳跃高度，低于50%无法二段跳
  - 饱腹度超过80%→繁殖后代，影响下一局初始饱腹度

  危险：
  - 巨大皮鞋（中间有空隙可以安全穿过）
  - 蟑螂药（圆形吸引范围，靠近会被拉过去毒死）
  - 长大的小虫子会吃掉你

  道具：
  - 可推动方块（解开压力板谜题）
  - 可破坏方块（从上方跳下破坏）
  - 压力板（激活机关）

【文件结构】
  index.html       主游戏入口（双击即玩）
  config.js        全局参数配置
  editor.html      关卡编辑器（拖拽放置、框选调参）
  levels/          关卡数据（JSON）
  assets/          美术资源（待添加）
  README.txt       本文件

【技术说明】
  - 纯 HTML5 Canvas + 原生 JavaScript
  - 零外部依赖，无 CDN 调用
  - 仅支持 PC 端 Chrome 浏览器游玩
  - 未适配手机端

【参数调整】
  编辑 config.js 可调整所有游戏数值：
  - 跳跃高度 / 重力
  - 饱腹度衰减速度
  - 小虫子成长速度
  - 敌人参数
  - 等等...
